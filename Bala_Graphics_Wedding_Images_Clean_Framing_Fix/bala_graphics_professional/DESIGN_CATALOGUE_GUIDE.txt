HOW TO ADD YOUR OWN DESIGNS
Edit js/script.js and add an object to the `designs` array. Use:
- category: "Wedding", "Invitation", "Photo Frame", or "Litho"
- For Wedding, set size to one of the exact wedding size labels above.
- For Invitation, set invitationType to "Offset" or "Multicolor" and size to the exact matching subcategory.
- Set image and downloadFile to the image path inside the images folder.
- Do not add prices to invitation designs.

NOTE
The same sample image is reused for some sizes because the project only contains a limited number of sample artworks. These are demonstration assignments, not confirmation that the artwork is the final design for that print size.
